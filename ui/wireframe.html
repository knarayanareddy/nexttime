Input alternatives

One rehearsal, multiple ways to participate

VoiceOver and Switch Control can use tap-to-start/stop. Text completion is labeled non-speaking practice and is never framed as a lesser result.

Reduced motion uses this static recording indicator. There is no pulsing red control or repeated haptic.

Interaction and state annotations
  • Recording uses icon, text, elapsed time, and stop control—not red alone.
  • Microphone denial opens the text route without losing the rehearsal.
  • Processing status includes cancel/retry and does not immediately display negative correction.

Revocation ≠ deletion

Separate consequences

Revoking Bee stops future access. It does not silently delete unrelated local attempts. Deletion confirmation names selected source items, derived attempts, and exports before anything is removed.

Interaction and state annotations
  • Bridge offline preserves local review and export controls.
  • Destructive confirmation lists categories rather than a vague “everything.”
  • Technical source details expand below the plain-language summary.
